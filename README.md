# ON:WAY

청소년 단체 이동 확인을 위한 모바일 웹 내부 시연 프로젝트입니다.
React 19 · TypeScript · Vite 기반이며, 관리자와 인솔자 화면을 제공합니다.

## 실행

Node.js 22.18 이상을 설치하고 이 폴더에서 실행합니다.

```sh
npm install
npm run dev
```

표시되는 로컬 주소로 접속하세요.

## 검증 및 빌드

```sh
npm test
npm run build
```

웹 빌드 결과는 dist/에 생성됩니다. 설치 없이 열 수 있는 단일 시연 HTML은 다음 명령으로 생성합니다.

```sh
npm run build:demo
```

생성된 ONWAY-demo.html을 브라우저에서 엽니다. GitHub 저장소의 index.html은 개발용 진입점이므로 파일을 더블클릭하는 방식으로 실행하지 않습니다.

pnpm 사용자는 pnpm-lock.yaml을 이용할 수 있습니다. npm install로 새로 생성한 package-lock.json은 npm을 표준 도구로 정한 경우 저장소에 함께 커밋하세요.

## 사용 흐름

1. 관리자 화면에서 단체명, 이동일, 인원을 등록합니다. 출발지는 선택 입력이며 생략하면 단체명을 사용합니다.
2. 확인 지점 관리에서 출발지·휴게소·점심식사 장소·고흥IC·나로1대교를 선택합니다. 다른 장소도 직접 추가할 수 있습니다.
3. 손잡이를 드래그해 순서를 변경합니다. 장소명을 더블클릭하거나 키보드로 선택 후 Enter를 눌러 수정합니다.
4. 인솔자 화면에서 단체정보를 확인하고 인원·식사 장소를 수정합니다. 이동 버튼은 현재 시각으로 즉시 기록하며 직전 기록을 되돌릴 수 있습니다.
5. 관리자 화면에서 인원 비교, 마지막 확인, 기록 수정·취소 이력을 확인합니다. 목록 행 전체를 눌러 단체를 선택할 수 있습니다.

## 저장 범위와 현재 한계

- 같은 브라우저의 localStorage에만 저장합니다. 저장 키는 onway-workspace-v2이며 기존 onway-demo-v1 데이터는 자동 이전합니다.
- 서버, 로그인, 권한 검증, 기기 간 동기화, 푸시 알림은 아직 없습니다. 화면 전환 버튼은 시연용입니다.
- 실제 GPS, 지도, 날씨, 사고 API는 연결되지 않았습니다. 지도는 개념도이고 거리·도착 시각·환경 안내는 예시입니다.
- GitHub에 올리거나 정적 웹으로 배포해도 휴대폰과 관리자 기록이 공유되지는 않습니다.
- 브라우저에 입력했던 실제 기록은 이 소스에 포함되지 않습니다. 소스에는 한빛초등학교 등의 예시만 있습니다.
- 시연 초기화는 선택한 단체만 대상으로 합니다. 브라우저 저장 데이터를 삭제하면 해당 브라우저의 기록도 사라집니다.

## 주요 파일

- src/Admin.tsx: 관리자 등록·목록·이력
- src/CheckpointEditor.tsx: 지점 선택·장소명 수정·드래그 정렬
- src/main.tsx: 인솔자 화면·화면 전환
- src/workspace.ts: 단체별 저장·이전·관리자 작업
- src/services.ts: 이동 기록·인원·식사 상태 처리
- src/data.ts: 일정 및 예시 데이터
- src/Visuals.tsx: 여정 개념도와 아이콘
- tests/: 상태·저장·단체 분리 테스트
- scripts/package-demo.mjs: 단일 HTML 생성
