# 주간식단표

관리자 화면의 **센터 주간 식단표 관리**에서 PDF 또는 이미지를 선택합니다. 원본의 7일 날짜 열과 아침·점심·저녁 메뉴 영역을 읽어 미리보기를 만들며, 단체명과 인원 영역은 제외합니다. 인식 결과를 확인하고 **식단표 저장 · 단체에 적용**을 누르면 같은 주의 모든 단체가 해당 메뉴를 사용합니다. 같은 주에 다시 등록하면 그 주의 식단이 교체됩니다.

인솔교사 입소안내의 식단표는 등록된 이동일과 숙박 기간을 사용합니다. 1박 2일·2박 3일은 입소일 저녁부터 퇴소일 점심까지 표시합니다. 입소일 점심 선택 시 해당 점심을 추가합니다. 당일 일정은 선택한 점심만 표시하며, 숙박 기간 미등록 시 임의로 기간을 추정하지 않습니다. 주를 넘는 일정은 두 주의 자료를 조회합니다. 원본의 빈 메뉴는 다른 날짜의 메뉴로 채우지 않습니다.

센터의 7열 주간식단표 양식을 지원합니다. 텍스트가 있는 PDF는 위치 정보를 이용하며, 스캔 PDF·PNG·JPG는 로컬 OCR을 사용합니다. 이미지 인식은 오탈자가 생길 수 있어 저장 전 확인 안내가 표시됩니다. 날짜나 메뉴 경계를 구분할 수 없는 양식은 오류로 알리고 기존 등록 자료를 유지합니다. 최대 10MB, PDF 최대 3페이지입니다.

로컬 시연은 브라우저 localStorage에 주 단위로 저장됩니다. 공유 접속은 인증된 `/api/shared/weekly-menus`를 통해 비공개 documentStore에 저장됩니다. 관리자만 등록할 수 있고, 인솔교사는 자신의 입소 기간만 조회할 수 있습니다. 공유 서버에는 변경된 백엔드를 배포·재시작해야 합니다. 로컬 화면에서만 저장한 자료는 공유 서버로 자동 전송하지 않습니다.

`pnpm build`는 PDF/OCR 자산을 준비합니다. 첫 빌드 시 한국어 OCR 모델을 다운로드하며, 업로드한 문서는 외부 인식 서비스로 보내지 않습니다. 인식 라이브러리는 파일 선택 시 지연 로드합니다.

검증: `node --experimental-strip-types --test tests/weekly-meals.test.ts tests/documents.test.ts`. 실제 센터 PDF로 2026-11-13 입소, 점심 포함 선택, 빈 저녁, 저장 후 재조회, 360/390px 표를 별도로 확인했습니다.
